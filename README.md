# Базы данных в веб-разработке (SQL, NoSQL)

Ссылка на сайт: https://9kubovich.github.io/websittbd/

Учебный проект по верстке. Сайт про базы данных - рассказывается чем отличаются SQL и NoSQL базы, когда что лучше использовать, как проектировать базу и как её защищать.

## Страницы сайта

- index.html - главная
- sql.html - про реляционные базы
- nosql.html - про нереляционные базы
- sravnenie.html - сравнение SQL и NoSQL (таблица)
- proektirovanie.html - проектирование БД, нормализация, индексы
- orm.html - ORM и работа с базой из кода
- bezopasnost.html - безопасность (SQL-инъекции и т.д.)
- materialy.html - видео и частые вопросы
- kontakty.html - форма обратной связи

## Технологии

- HTML5
- CSS3
- CSS фреймворк Blaze UI (https://blazeui.com)
- Адаптивная верстка, 3 брейкпоинта (до 768px, от 768px, от 992px)
- Адаптивные картинки через srcset и webp
- Бургер меню сделано на чистом CSS без JS (через чекбокс)
- Видео из VK Видео через iframe

## Как запустить

Скачать репозиторий и открыть index.html в браузере. Либо открыть папку в PyCharm и запустить через Open in Browser, никакой сборки не нужно, обычные html файлы.
