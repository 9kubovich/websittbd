# Базы данных в Web-разработке (SQL, NoSQL)

Ссылка на сайт: https://9kubovich.github.io/websittbd/

Многостраничный сайт про базы данных: реляционные (SQL) и нереляционные (NoSQL),
для чего они нужны и чем отличаются. Сделан для учебного проекта по вёрстке.

## Страницы

index, sql, nosql, sravnenie, proektirovanie, orm, bezopasnost, materialy, kontakty

## Как запустить

Скачать репозиторий и открыть index.html в браузере. Либо открыть папку проекта
в PyCharm и запустить index.html через "Open in Browser".

## Технологии

- HTML5
- CSS3, фреймворк Blaze UI
- адаптивная вёрстка (медиа-запросы для мобильных, планшетов и десктопа)
- адаптивные картинки (srcset, webp)
- видео из VK Видео через iframe
